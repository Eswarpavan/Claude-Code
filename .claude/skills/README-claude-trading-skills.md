# Claude Trading Skills (vendored)

The skill folders in this directory come from
[tradermonty/claude-trading-skills](https://github.com/tradermonty/claude-trading-skills)
(commit `e739008`), MIT License — see `LICENSE-claude-trading-skills`.

Claude Code loads them automatically from `.claude/skills/`. Some skills need API keys
(for example FMP, Finviz, Alpaca); see each skill's `SKILL.md`.

To update, re-copy the `skills/` folder from the upstream repository.

Not financial advice: the upstream project is for education and process improvement only.
